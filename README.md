# Web-Portofolio-Hanan-2025
Ini adalah website portofolio responsif yang dirancang untuk menampilkan informasi pribadi secara profesional. Website ini mencakup berbagai bagian seperti profil diri, karya-karya, galeri foto, hingga kontak, dengan tampilan modern dan animasi yang menarik.

✨ Fitur Utama
Desain responsif, cocok di berbagai perangkat (mobile, tablet, desktop)
Tampilan modern dengan layout bersih dan user-friendly
Animasi interaktif untuk meningkatkan pengalaman pengguna

Halaman terpisah untuk:
Beranda
Tentang Saya
Keterampilan & Proyek
Galeri
Kontak (dilengkapi dengan form)

🛠️ Teknologi yang Digunakan
HTML5
CSS3
JavaScript (untuk animasi dan interaktivitas)
PHP (untuk form kontak)
Font & Icon dari Google Fonts dan Font Awesome
